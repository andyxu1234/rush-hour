# 汽车华容道 · 微信小游戏 — 开发计划（交付给 coding agent 的完整规格）

> 本目录是**可执行的规格书**，不是概念稿。任何 coding agent 读完 `docs/` 即可从零开发出完整可上线的小游戏。
> 配套产物：`tools/rush_hour.py`（已跑通的参考求解器）、`data/levels.json`（已校验的内置关卡包）。

---

## 0. 一句话定义

6×6 棋盘上的滑块解谜游戏：把红车开到右侧出口，步数越少越好。
玩法内核极简，全部难度来自**关卡设计**与**手感打磨**——因此本项目的一半工作量在关卡生成/校验管线，而不是渲染。

## 2. 关键决策速览（已定，勿再摇摆）

| # | 决策 | 结论 | 理由（一句话） |
|---|---|---|---|
| D1 | 平台形态 | **微信小游戏**（非小程序） | 小程序做游戏会被判"非游戏"驳回；小游戏才有广告变现与游戏类目 |
| D2 | 前端技术 | **纯 TypeScript + Canvas 2D，代码优先，不用 Cocos/Laya** | GUI 编辑器产出的场景/预制体 coding agent 无法可靠生成，代码优先才能全流程自动化开发与测试 |
| D3 | 双端复用 | **同一套代码编译到 H5 与 小游戏** | H5 用于开发/CI/自动化测试，小游戏用于发行；复用率 ~95% |
| D4 | 计步口径 | **默认＝滑动次数**（一辆车滑一次算一步，不论几格） | 与经典 Rush Hour 的"最少步数"口径一致；格数作为副指标另存 |
| D5 | 后端 | **首版微信云开发；同时实现自建 FastAPI 版本，接口一致可切换** | 云开发免备案域名、零运维、免 ICP；FastAPI 版匹配团队技术栈且是面试亮点 |
| D6 | 关卡来源 | **程序化生成 + 求解器校验**，不用人工摆放 | 手工摆关卡必然产出不可解/极简解的死局（本项目已实测踩坑，见 `01` 定理 2） |
| D7 | 防作弊 | **提交完整走子序列，服务端重放校验** | 关卡规则确定，重放成本极低而收益彻底 |
| D8 | 变现 | **IAA 纯广告**（激励视频换提示 + 插屏），个人主体即可上线 | 内购需版号（企业主体、半年起步），首版不做 |
| D9 | 难度主指标 | 最少滑动步数 `par.moves` | 玩家可见、可比较、可做星级门槛，无需解释 |
| D10 | 关卡包发布 | 内置离线包 + 服务端热更新（版本号比对） | 首包不塞满关卡，包体可控；活动/每日挑战走热更 |

## 4. 里程碑概览

| 阶段 | 目标 | 出口标准（DoD 摘要） |
|---|---|---|
| **P0** 脚手架 | 工程能构建、能真机跑起一个 Canvas | 手机上出现棋盘网格 |
| **P1** 玩法内核 | `packages/core` 纯逻辑完备 | 单测覆盖率 ≥95%，与 Python 求解器结果逐关一致 |
| **P2** 渲染交互 | 可玩 | 真机完成 10 关，手感达标 |
| **P3** 关卡系统 | 内置 60+ 关 | 每关通过全部关卡不变量校验 |
| **P4** 外围与留存 | 完整单机游戏 | 选关/存档/引导/分享/每日挑战可用 |
| **P5** 后端接入 | 账号与云存档 | 换设备进度不丢；排行榜数据服务端校验通过 |
| **P6** 编辑器与扩产 | 关卡可自产自审 | 编辑器产出关卡能一条命令进包 |
| **P7** 变现与上线 | 过审上线 | 审核通过，流量主开通，埋点齐全 |

详细的阶段任务分解见 `05-development-plan.md`。

## 5. 已知硬约束（摘自微信官方规则，落地方案须遵守）

| 约束 | 数值 | 影响 |
|---|---|---|
| 主包体积 | ≤ 4 MB（超出的走分包） | 关卡数据与音频必须分包/远端化（`02` 有包体预算表） |
| 总体积 | 主包 + 分包 ≤ 30 MB | — |
| 运行环境 | 无 DOM / 无 BOM，禁 `eval` / `new Function` | 不能直接复用浏览器库，需适配层 |
| 网络域名 | 必须 HTTPS 且在后台配置白名单 | 自建后端需备案域名；云开发无此问题 |
| 好友关系链 | 只能在**开放数据域**子包获取 | 好友排行榜需独立子包 |
| 个人主体 | 只能 IAA 变现，不能开内购/微信支付 | 无版号也能上线（需软著或电子版权认证 + 自审自查报告） |
| 流量主 | 累计独立访客 UV ≥ 1000 才能开通 | 上线后需先做冷启动拉新，广告点位要预留但不依赖 |

> 以上数值以微信公众平台/开发文档**当前版本**为准，提审前须复核（`06` 的发布 checklist 含复核项）。
