设计决策

  • 不用纯白底：屏幕底色是白 → #E6EBF1 的三段梯度，面板才有纵深。
  • 显示体用工业压缩体（Bahnschrift Condensed / DIN Alternate），步数与关卡号做成大号数字， 靠字号落差（30px 对 10px）建立层级，不靠装饰线。
  • 唯一高亮物是红车：其余车全部去饱和靠后，玩家视线永远先找到红车。
  • 出口做成闸机：黄黑危险条纹 + 绿色开口，红车对准时开口呼吸发光——这是全 App 的记忆点。
  • 同关内车色互不相同：10 车关用 10 种互斥色，避免玩家误以为同色车可互换。
  • 触控目标全部 ≥44px，底部三个主按钮为 52px 圆形。

交付说明
1. 本文件是**设计基线**，不是可直接发布的页面。真机上所有棋盘/车辆/闸机都必须用 Canvas 矢量绘制 （见 01-game-design.md 第 7 节"所有美术资源优先用代码绘制"），本文件里的 CSS 车辆只是它的等价视觉定义。
2. 棋盘上的关卡数据取自 data/levels.json： SCREEN 02 用 c001（6 车 / 4 步）、SCREEN 04–08 用 c004（10 车 / 11 步）。
3. 提示文案"灰色车向右滑 2 格"来自求解器对该关算出的最优首步，不是示意文字。
4. 尺寸约束：设计分辨率 375×667，渲染按 devicePixelRatio 缩放上限 3×；触控目标全部 ≥44px。
5. 待补：新手引导遮罩（依赖 t01/t02/t03 棋盘）、每日挑战页、胜利驶出动画关键帧、iPad 横屏适配。
